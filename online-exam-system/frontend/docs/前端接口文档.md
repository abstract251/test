# 前端接口文档

本文档基于当前 `backend` 仓库代码整理，供前端联调使用。

## 1. 基本信息

### 1.1 基础地址

按当前服务启动地址拼接，例如：

```txt
http://localhost:8080
```

### 1.2 统一返回格式

```json
{
  "code": 200,
  "message": "请求成功",
  "data": {}
}
```

字段说明：

- `code`: 业务状态码，`200` 为成功
- `message`: 提示信息
- `data`: 业务数据

### 1.3 登录态

登录成功后后端会通过 Cookie 返回：

- `rb_token`: 当前账号主键
- `rb_role`: 当前账号角色

角色值：

- `0`: 管理员
- `1`: 教师
- `2`: 学生

前端调用需要身份的接口时，必须自动携带 Cookie。

### 1.4 路径占位规则

学生和教师的分页筛选接口使用路径参数，不支持直接缺省。对于“不筛选”的字段，请传 `@`。

示例：

```txt
GET /students/1/10/@/@/@/@/@/@/@
GET /teachers/1/10/@/@/@/@/@/@
```

### 1.5 题型编号

- `1`: 选择题
- `2`: 填空题
- `3`: 判断题

### 1.6 分页对象

分页接口基本使用 MyBatis-Plus `Page` 结构，常见字段包括：

- `records`: 当前页数据
- `total`: 总条数
- `size`: 每页条数
- `current`: 当前页码
- `pages`: 总页数

## 2. 推荐对接顺序

正式前端建议优先这样对接：

1. 登录 `POST /login`
2. 管理后台侧使用用户、题库、试卷、考试、成绩、消息接口
3. 学生考试侧使用新的考试会话流：
   - `POST /student/exam/{examCode}/attempt/start`
   - `PUT /student/exam/{examCode}/attempt/answers`
   - `POST /student/exam/{examCode}/attempt/submit`
4. 题库列表统一使用 `GET /question-bank/{page}/{size}`
5. 正式考试查看固定试卷内容时，教师/管理员使用 `GET /exam/{examCode}/frozen-paper`

`POST /answer/submit` 仍可用，但更适合作为兼容接口或简单联调接口，不建议作为正式考试页的第一选择。

## 3. 认证与登录

### 3.1 登录

- 方法: `POST`
- 路径: `/login`
- Body: `Login`

请求示例：

```json
{
  "username": 10001,
  "password": "123456"
}
```

成功时：

- 管理员返回 `Admin`
- 教师返回 `Teacher`
- 学生返回 `Student`
- 同时写入 `rb_token` 和 `rb_role` Cookie

### 3.2 登出

- 方法: `POST`
- 路径: `/logout`
- Body: 无

作用：

- 清空 `rb_token`
- 清空 `rb_role`

## 8. 全局题库接口

### 8.1 全局题库聚合分页

- 方法: `GET`
- 路径: `/question-bank/{page}/{size}`
- 路径参数:
  - `page`: 页码
  - `size`: 每页条数
- Query 参数:
  - `questionType`: 可选，题型编号 `1/2/3`
  - `subject`: 可选，科目精确筛选
  - `keyword`: 可选，题干关键字模糊搜索
- 返回: `Page<QuestionBankItemVO>`

示例：

```txt
GET /question-bank/1/10
GET /question-bank/1/10?questionType=1
GET /question-bank/1/10?subject=计算机网络&keyword=多路复用
```

### 8.2 删除题库题目

- 方法: `DELETE`
- 路径: `/question-bank/{questionType}/{questionId}`
- 路径参数:
  - `questionType`: 题型编号 `1/2/3`
  - `questionId`: 题目编号
- 返回字段:
  - `questionType`
  - `questionTypeName`
  - `questionId`
  - `deletedPaperRelations`
  - `deletedQuestion`

说明：

- 如果题目关联的试卷已经冻结，接口会拒绝删除
- 删除时会先删试卷题目关联，再删题库题目本身

- 方法: `POST`

- 方法: `GET`

  - `inExamWindow`

- 方法: `GET`
- 路径: `/exam/{examCode}/frozen-paper`

  - 仅教师/管理员可访问

- 说明:
  - 仅在进入冻结窗口后才可读取
  - 考试撤销后不可读取

### 10.10 撤销考试

- 方法: `POST`
- 路径: `/admin/exam/{examCode}/revoke`
- Body:

```json
{
  "reason": "考试安排有误，撤销重开"
}
```

限制：

- 仅超级管理员可操作
- `reason` 必填

## 11. 学生考试会话接口

### 11.1 开始或恢复考试

- 方法: `POST`
- 路径: `/student/exam/{examCode}/attempt/start`
- 需要登录: 是
- 角色要求: 学生
- Body: 无
- 返回字段:
  - `attemptId`
  - `serverTime`
  - `windowEndAt`
  - `paper`: 脱敏后的试卷内容，结构同 `Map<Integer, List<?>>`
  - `answers`: 已暂存答案，键格式为 `questionType_questionId`

说明：

- 试卷中的标准答案和解析会被隐藏
- 如果学生已开始但未交卷，再次进入会恢复作答状态

### 11.2 暂存答案

- 方法: `PUT`
- 路径: `/student/exam/{examCode}/attempt/answers`
- 需要登录: 是
- 角色要求: 学生
- Body:

```json
{
  "answers": {
    "1_10001": "A",
    "2_20003": "TCP",
    "3_30002": "T"
  }
}
```

说明：

- key 格式固定为 `questionType_questionId`
- 会与历史答案合并保存

### 11.3 正式交卷

- 方法: `POST`
- 路径: `/student/exam/{examCode}/attempt/submit`
- 需要登录: 是
- 角色要求: 学生
- Body: 无
- 返回字段:
  - `etScore`: 得分
  - `maxScore`: 满分
  - `passed`: 是否通过
  - `correctCount`: 正确题数
  - `totalQuestions`: 总题数

说明：

- 判分依据为冻结快照对应的试题
- 已交卷后不可重复提交

## 16. 对接注意事项

- 学生访问 `GET /paper/{paperId}` 和 `GET /exam/{examCode}/frozen-paper` 会被拒绝
- 试卷和考试一旦进入冻结窗口，很多修改类接口会被业务拒绝
- 题库删除也会受冻结考试影响
- 教师/学生筛选接口请使用 `@` 表示不筛选
- 部分历史接口不是严格 REST 风格，例如：
  - `GET /paper/delete/{paperId}/{type}/{questionId}`
  - `GET /admin/resetPsw/{adminId}/{oldPsw}/{newPsw}`
- 新考试页优先对接学生考试会话流，不建议只依赖 `POST /answer/submit`
