# Frontend Copy Guideline

## 目标

本项目页面文案统一遵循以下三点：

1. 去掉研发过程描述，不在页面展示“第几版”“后端待接入”“占位联调”等信息。
2. 保留用户必要操作提示，只说明“现在能做什么、下一步怎么做”。
3. 统一标题、副标题、空状态与按钮语气，保持简短、直接、可执行。

## 写作规则

- 标题：使用功能名，控制在 2-6 个字，例如“考试管理”“试卷编辑”。
- 副标题：一句话说明页面用途，不描述技术实现细节。
- 空状态：说明当前状态 + 用户可执行动作，例如“暂无考试数据，请先新建考试”。
- 按钮：统一使用动词短语，例如“新建考试”“保存修改”“返回列表”“退出登录”。

## 禁用表达

以下文案不应出现在页面中：

- 研发过程：`第一版`、`本期`、`联调`、`预留结构`、`占位页`
- 技术实现：`后端接口`、`/practice/{source}`、`/paper/{paperId}`、`当前版本规则`
- 交付说明：`待实现`、`后续接入`、`功能建设中`

## 推荐表达示例

- 登录页说明：
  - 推荐：`支持管理员、教师、学生三类账号登录，登录后自动进入对应工作区。`
  - 不推荐：`第一版优先打通登录...`

- 试卷编辑说明：
  - 推荐：`左侧为科目题库，右侧为当前试卷题目。`
  - 不推荐：`来自 /practice/{source}，按后端规则计分。`

- 占位功能页：
  - 推荐：`该功能暂不可用，请先使用其他已开放功能。`
  - 不推荐：`等待后端接口完成后继续联调。`
