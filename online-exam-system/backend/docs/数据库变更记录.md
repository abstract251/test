## 2026-04-15 JWT + Spring Security 鉴权改造

| 项目 | 内容 |
|------|------|
| 关联需求 | JWT 登录、刷新令牌、Spring Security 权限控制、BCrypt 密码存储 |
| 脚本 | [auth_security_upgrade.sql]|
| 影响 | 新增表 `auth_refresh_token`；登录态从 Cookie 切换为 Bearer Token；旧账号密码需迁移为 BCrypt |
| 当前检查结果 | `auth_refresh_token` 表已存在，结构与脚本一致，当前记录数为 `0` |
| 表结构摘要 | `id`、`jti`、`user_id`、`role`、`username`、`expires_at`、`revoked`、`created_at` |
| 索引 | 主键 `id`；唯一索引 `jti`；索引 `idx_auth_refresh_token_user_role`、`idx_auth_refresh_token_expires_at` |
| 验证方式 | 执行 `POST /auth/login` 后再调用 `POST /auth/refresh`，随后检查 `auth_refresh_token` 是否新增记录并发生轮换 |

## 迁移注意事项

- 执行 `auth_security_upgrade.sql` 只会创建 refresh token 表和索引，不会自动迁移旧密码
- 现有 `admin`、`teacher`、`student` 表中的明文密码需要先迁移为 BCrypt 哈希
- 前端切换到 `/auth/*` 前，应确认数据库脚本已执行且密码迁移完成
