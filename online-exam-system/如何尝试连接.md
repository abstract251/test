### 后端搭建
首先用pom.xml导入maven
进入backend/src/main/java/com/test/oes/
OnlineExamSystemApplication.java
点击IDEA的构建
成功后即可进入前端搭建

### 前端搭建

确保Node.js已下载至IDEA中（一般识别到后就会自动下载）
然后在终端进入frontend目录
执行 
```
npm install
```
等待安装完成后
执行
```
npm run serve    
```
见到如下显示即为成功
```
> exam-web@0.1.0 serve
> vue-cli-service serve

 INFO  Starting development server...


 DONE  Compiled successfully in 13715ms                                                                                                                            11:47:17


  App running at:
  - Local:   http://localhost:8081/ 
  - Network: http://10.133.132.141:8081/

  Note that the development build is not optimized.
  To create a production build, run npm run build. 
```

在浏览器打开 http://localhost:8081/
正常显示无误即可
